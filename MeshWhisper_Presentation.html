SECURITY ARCHITECTURE • CRYPTOGRAPHIC PROTOCOL

Zero-Trust Cryptography & Identity-Based Certificates (IBC)

Mathematical verification replaces centralized Certificate Authorities, phone numbers, and cloud keys.

DUAL ASYMMETRIC KEYPAIR ARCHITECTURE (Ed25519 + X25519)

  • Ed25519 Signatures: Authenticates LINK_AUTH handshakes and prevents forged relay packets.
  • X25519 Diffie-Hellman (ECDH): Derives ephemeral session keys per peer without key servers.
  • IBC Certificates: Self-signed cryptographic identity certificates validated offline.

AEAD SYMMETRIC ENCRYPTION (ChaCha20-Poly1305)

  • 256-bit Cipher: Encrypts all payloads with authenticated Additional Data (AAD).
  • Header Tamper Resistance: Wire headers (type, packetId, senderId, timestamp) bound into Poly1305 MAC.
  • Ephemeral Ratchet: Rotates keys periodically for Post-Compromise Security (PCS).

ANTI-TAMPER LOCAL STORAGE & HARDWARE SECURITY

  • SQLCipher AES-256: SQLite database encrypted at rest with hardware PBKDF2 derivation.
  • Android Keystore / StrongBox: Isolates root identity keys in tamper-resistant hardware.
ROUTING PROTOCOL • TRAFFIC MANAGEMENT

Controlled Flooding, Bounded Dedup Cache & 4-Tier QoS Egress

Preventing broadcast storms and buffer saturation across lossy, multi-hop radio links.

BOUNDED IN-MEMORY LRU DEDUP CACHE (50,000 PACKETS)

Pre-auth Stage S2 dedup check executes in < 0.2 μs entirely in RAM. Dropped duplicates prevent infinite relay loops and broadcast storms before expensive decryption.

ADAPTIVE TTL & LOOP INVARIANTS

Packets originate with TTL = 7. Every relay decrements TTL and checks invariants. Packets with senderId == myNodeId are dropped to break reflection cycles.

STARVATION-FREE 4-TIER QOS EGRESS SCHEDULER

  • Tier 0 (SIGNALING): Emergency SOS & LINK_AUTH handshakes transmit with zero queue delay.
  • Tier 1 (REALTIME_VOICE): 40ms Opus audio frames bypass standard chat queues.
  • Tier 2 (STANDARD_MSG): Direct E2EE chat messages with guaranteed delivery.
  • Tier 3 (BULK_TRANSFER): Background media chunks and route telemetry.
INGESTION ENGINE • FORMAL SPECIFICATION

Stage S0 to S7: Mandatory Production Authentication Chokepoint

Zero unauthenticated state mutation — every incoming frame passes 8 strict architectural stages.

S0: ADMISSION & S1: STRUCTURE

UDP mesh packets forbidden unconditionally. PENDING links restricted strictly to LINK_AUTH handshakes. Frame length validated [37..2048 bytes].

S2: ANTI-REPLAY & S3: FRESHNESS

LRU dedup drops loops instantly. Replayed DMs re-emit ACK safely. Strict timestamp window (-120s to +60s) rejects replayed frames.

S4: TRUST & S5: CRYPTOGRAPHY

Validates sender identity trust; senderId must match bound link. ChaCha20-Poly1305 MAC tag and digital signature transcripts verified.

S6: HOP DECREMENT & S7: DISPATCH

Decrements TTL and evaluates forwarding. Commits packetId to seen set and dispatches to UI and database. Voice frames skip DB writes.

VOICE ENGINE • REAL-TIME AUDIO STREAMING

Low-Latency Full-Duplex Voice Calling Over BLE & Local Wi-Fi

Wideband Opus streaming, adaptive jitter buffering, and pure-RAM ephemeral link binding.

WIDEBAND OPUS AUDIO ENCODING (16 kHz / 24 kHz)

Samples microphone audio at 16–24 kHz and compresses to 12–24 kbps into compact 40ms packets. Integrated Acoustic Echo Cancellation (AEC) and hardware Noise Suppression.

ADAPTIVE JITTER BUFFER & PACKET LOSS CONCEALMENT (PLC)

Buffer depth adapts dynamically between 60ms and 180ms based on measured radio packet arrival jitter. Opus PLC synthesizes missing waveforms smoothly during temporary RF fades.

ZERO DB MUTATION & EPHEMERAL LINK SECURITY

Voice frames stream strictly in RAM (0 database writes) to prevent memory leaks and cold-boot flash extraction. Authenticated link binding prevents packet forgery.

MEDIA ENGINE • PROGRESSIVE TILES & CHUNKING

Streaming Photos, Voice Notes & Files Across Narrowband Radios

MTU-aware chunking, selective NACK retransmission, and progressive matrix tile rendering.

450-BYTE MTU SEGMENTATION & SHA-256 INTEGRITY

Files up to 20MB are split into 450-byte encrypted fragments. SHA-256 Merkle root verification guarantees byte-exact reassembly with zero corruption.

PROGRESSIVE MATRIX TILE REVEALER

Photos are split into 2x2 or 3x3 compressed tiles. An immediate low-res preview (≤ 350B) renders instantly, followed by real-time progressive unblurring as chunks arrive.

SELECTIVE NACK RETRANSMISSION & PACING

Receiver watchdog requests only missing chunk indices (0% full-file retransmit waste). Congestion-aware write pacing (65ms on BLE, 12ms on Wi-Fi) prevents buffer overflow.
